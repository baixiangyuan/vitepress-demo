# 主菜单按键速览

> 基于 **v3.1.6** 的 `main.py` / `cli/app.py` 实际菜单整理。启动 `python main.py` 后按提示输入选项（0-7/9/A-Z/ALL/AR/BN/MM/RT/WB/WL/RM/SW/WH）。

## 核心操作

| 按键 | 指令 | 说明 |
|------|------|------|
| `1` | 🚀 启动机器人 | 选择「智能省 token 模式」（长时挂机：跳过封面与 ASR、用快速模型、关深度搜索等）或「按已保存配置运行」 |
| `2` | ⚙️ 配置AI参数 | 调整每轮浏览的视频数、模型角色、回复风格等 |
| `3` | 🔑 配置登录 | 配置 SESSDATA Cookie、扫码登录或手动输入 |
| `4` | 📚 管理知识库 | 检索、编辑、整理已学内容，导入/导出 |
| `5` | 🎯 管理兴趣爱好 | 配置与编辑 AI 偏好的视频类型权重 |
| `6` | 💬 评论互动设置 | 评论自动互动设置（受全局安全策略约束） |
| `7` | 📩 私信设置 | 开启自动回复私信，定义对话风格与记忆档位 |
| `9` | 🔍 视频探索 | 搜索→观看→总结 / 自动刷视频 |

| `BN` | 📝 图文学习笔记 | BV/链接 → 目录+AI配图全过程讲解 |
| `K` | 🔄 知识库重温 | 选择已学视频，重新观看/优化 |

## 系统与配置

| 按键 | 指令 | 说明 |
|------|------|------|
| `R` | ♻️ 恢复出厂设置 | 输入 `RESET` 一次确认，清除全部用户数据 |
| `S` | 🛡️ 关键词审查开关 | 回复安全审查开/关 |
| `ALL` | 🎛️ 全部设置 | 网页端和命令端共用的完整设置 |
| `Q` | ⚡ 快速模式 | 跳过真人延迟（模拟真人节奏开关） |
| `Z` | 🔇 安静模式 | 精简日志输出 |
| `E` | 📤 导出配置 | 备份所有设置到一个文件 |
| `I` | 📥 导入配置 | 从备份文件一键恢复所有设置 |
| `O` | 🗂️ 一键整理知识库 | 非 3 层文件 → AI 自动归类到 3 层 |
| `N` | 📝 自定义知识管理 | 自定义知识条目增删改查 |
| `C` | 🖼️ 封面分析开关 | 开启/关闭封面视觉分析（关闭刷视频更快） |
| `L` | 💤 待机模式设置 | @触发总结/ASR/评论区/PPT 等 |
| `RT` | 📡 实时监听设置 | 私信 + 全站@我 + 视频问答 |
| `Y` | ⏱️ 视频间隔设置 | 视频浏览间隔范围 |
| `P` | 🎯 兴趣偏好设置 | 智能引擎 v2.0 |
| `X` | 🪙 投币限制设置 | 每日上限/评分阈值/概率/冷却 |
| `AR` | 🧐 AI 行为审核设置 | 含桌面通知 |
| `WB` | 🌐 打开网页端 | 自动启动并打开浏览器面板 |

## 队列与历史

| 按键 | 指令 | 说明 |
|------|------|------|
| `WL` | 📌 稍后再看管理 | 查看/添加/移除/清空（v3.1.6 含本地持久观看队列） |
| `RM` | 📝 待办与提醒 | 列表/添加/删除 |
| `SW` | 🔔 功能开关 | 评论/回复/点赞/投币/收藏/关注等 |
| `WH` | 📜 观看历史 | 本地观看历史列表 |
| `0` / `Q` 菜单外 | 🛑 退出 | 安全关闭当前会话 |

::: tip 启动方式选择
按 `1` 启动机器人时会先选择运行模式：**智能省 token 模式**适合长时挂机（跳过封面与 ASR、使用快速模型、关闭深度搜索/推荐/心理深度分析/知识验证），**按已保存配置运行**则完全遵循配置文件。
:::
