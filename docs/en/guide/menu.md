# Main Menu Key Reference

| Key | Command | Description |
|-----|---------|-------------|
| `1` | 🚀 Start Bot | Run the fully automated video-browsing and interaction loop |
| `2` | ⚙️ Configure AI | Tune videos-per-round, model role, reply style, etc. |
| `3` | 🔑 Bilibili Login | Configure SESSDATA Cookie, QR-scan login, or manual input |
| `4` | 📚 Knowledge Base | Search, edit, organize learned content; import/export |
| `5` | 🎯 Interests | Configure and edit the weight of AI-preferred video types |
| `6` | 💬 Comment Settings | Enable auto comment interaction; configure reply pacing and mode |
| `7` | 📩 DM Settings | Enable auto DM replies; define conversation style and memory tier |
| `8` | 🧬 Diary / Evolution | View AI reflections, persona evolution, and the lowest-level run diary |
| `9` | 🛠️ Agent Skills | Plug in extended tasks via Search API, auto-search, auto-learn |
| `L` | 📡 Listen Mode | Switch to minimal-CPU listening mode; only watches DMs and comments |
| `V` | 📹 Manual Analyze | Proactively parse a specified video and archive it |
| `W` | 🎨 Video → PPT | Turn a video into a beautiful PPT card-style web page |
| `R` | 🔄 Reset Config | Reset the config file to its initial state |
| `E` | 📤 Export | Desensitized export of all config and logs to a ZIP file |
| `WL` | 📌 Watch Later | View / add / remove / clear the "Watch Later" list (requires Bilibili login) |
| `RM` | 📝 To-Do & Reminders | View / add / delete local to-dos and reminders |
| `SW` | 🎛️ Feature Toggles | View and toggle 14 feature switches (aligned with web-panel defaults) |
| `WH` | 📜 Watch History | View local watch history (most recent 50 entries) |
| `H` | ❓ Help | Show operation help and key descriptions |
| `Q` / `0` | 🛑 Quit | Safely close the current session |
